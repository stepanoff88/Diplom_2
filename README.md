# Diplom_2

Сделал проект с API тестами для Stellar Burgers.

Что внутри:
- Maven проект на Java 11, подключены JUnit 5, RestAssured и Allure.
- Пять классов тестов: регистрация, логин, изменение данных пользователя, создание заказа и получение заказов.
- Всего 22 теста. В каждом проверяю код ответа и тело.
- Все шаги вынесены в отдельные методы с аннотацией @Step.
- Тестовые пользователи создаются перед тестом и удаляются после.
- Allure отчет лежит в папке allure-report, открывать нужно файл index.html.

Запуск тестов:
mvn clean test

Пересобрать отчет:
mvn clean test allure:report
